# 01 · First 60 Seconds and Screen Flow

Device: iPad landscape (design canvas 1194 × 834 pt). Child-facing text is English, lowercase, in a single-storey-a font (Andika recommended). Thai appears only in adult text.

## The first 60 seconds Iris experiences

Before this, a grown-up has finished the one-time setup (see Flow A). The clock starts when Iris is handed the iPad on Home.

What she never sees in the first minute: a timer, a score, a wrong-answer buzzer, a capital letter, or a word she hasn't been taught.

## Flow A · First launch

```
[App icon]
   │
   ▼
[Welcome · grown-up]  EN/TH toggle. "Set up for your child" (1 screen)
   │  child's first name (shown only in Parent Area), Thai help on/off
   ▼
[Sound check · grown-up]  plays "sssss" + "sat". "Can you hear it?"  [Yes] [Play again]
   │  tip: use speakers or child headphones, quiet room
   ▼
[How a session works · grown-up]  5 stones, about 15 min, you can stop any time,
   │  some steps happen away from the screen (sound hunt, rice tray). [Start]
   ▼
[Home · child]  "Tap to start."  ▶ today = Level 1 · Page 1
   ▼
[Today's Lesson]  →  Stage 1 … Stage 5  →  [Session Finish]  →  [Home]
```

Setup is skippable after the first screen ("Set up later"), but the sound check is strongly suggested.

## Flow B · Lesson completion

```
[Stage 4 done] → [Session Finish]
   │  "All done for today." Pick 1 of 3 stickers (big, no wrong choice)
   │  optional soft chime (Parent Area toggle, on by default)
   ├── [⌂ home]          → Home. ▶ today now shows the next page
   ├── [↻ do it again]   → same page, Stage 1
   └── Page 5 only: [grown-up time] → hold 3 s → Parent check (mark skills)
```

Page state is saved locally when the sticker is chosen. Pages are marked **done** only on Session Finish. Doing a page again never removes its done mark.

## Flow C · Resuming and free navigation

```
[Home]  ▶ today → resumes the current page
   │
   ├─ page in progress?  yes → [Today's Lesson] with the half-done stone glowing
   │                          "Welcome back. Tap to go on."  ▶ → start of that stage
   │                     no  → next not-done page (or the page a grown-up pinned)
   │
   └─ Today's Lesson also shows all pages of the level as tabs: 1 2 3 4 5
      Any page in an open level can be picked (free learning).
      The next level opens after Page 5 is done, or when a grown-up opens it.
```

**Interruptions** (call, app switch, screen lock): audio stops immediately and the stage is saved. On return the screen is the same, and the 🔁 button pulses with **"Tap to hear it again."** Nothing auto-plays after an interruption.

**Finish early**: ⌂ home on any lesson screen asks **"Stop for today?"** with two picture buttons: ✋ stop / ▶ keep going. Stop saves the stage and goes to Session Finish (sticker still given, page not marked done). Home then offers to resume.

**Repeat a page**: "↻ do it again" on Session Finish, or Parent Area → "Stay on this page tomorrow" (pins ▶ today to that page).
